# Privacy Policy for Plurk Conversation Exporter

Effective date: 2026-09-05

Plurk Conversation Exporter is a browser extension for exporting a Plurk post and its replies.

## Data processing

The extension reads the currently selected Plurk conversation only after the user starts an extraction. It processes the conversation in the browser and does not send conversation text, author names, links, or images to a server operated by the extension developer.

When the user chooses to copy or export content, the result is written to the browser clipboard or saved to the local device. The result may contain personal information present in the conversation.

When the user chooses to download images, emotes, or create a DOCX file, the extension requests the relevant Plurk-hosted resources using the browser's current session. Those requests may include the user's existing Plurk authentication context and are subject to Plurk's own privacy policy and access controls.

## Data collection and sharing

The extension does not collect, sell, or share personal information with the extension developer or third-party analytics services. It does not use advertising, tracking, or an extension account.

## User control

The user controls when extraction, copying, downloading, and DOCX export occur. Removing the extension stops future processing by the extension. Files already copied or downloaded remain under the user's control and must be deleted separately.
