## 隱私與資料處理

- 對話內容只在使用者瀏覽器中處理，不會上傳到本專案的伺服器。
- 只有使用者主動擷取、複製或匯出時，才會處理目前 Plurk 頁面的內容。
- 下載圖片、表符或建立 DOCX 時，會使用目前瀏覽器的 Plurk 登入狀態存取相關資源。
- 輸出的檔案可能包含使用者名稱、訊息、連結與圖片，請確認自己有權保存或分享。

## 目前限制

- 尚未透過 Chrome Web Store 審核；手動安裝需要開啟 Chrome 開發人員模式。
- Plurk 頁面 DOM 或圖片 CDN 變更時，擷取及圖片匯出功能可能需要更新。
- Chrome Web Store 上架前，請以本專案的 GitHub Release 作為唯一官方下載來源，並留意重新發布的非官方版本。

Chrome Extension，用來將目前 Plurk 頁面的主噗與回覆整理成可複製、下載或匯出的內容，並支援 inline 圖片與表符。

## 目前功能

- 從目前 Plurk 交流頁擷取主噗與所有回覆，並在側邊欄預覽。
- 可選擇是否保留發言者，以及是否保留圖片與表符。
- 提供三種含格式複製方式：
  - **一般格式**：複製文字、圖片與表符，適合直接貼到 Google Docs。
  - **維持圖片尺寸**：不額外限制複製內容中的圖片顯示尺寸。
  - **使用原圖**：將 Plurk 縮圖改用原圖 URL，適合需要較大圖片的情況。
- 複製純文字：圖片與表符會以 `[圖片1]`、`[圖片2]` 等標記表示。
- 下載圖片與表符：將素材打包成 `Plurk-Conversation-Images.zip`，包含 `images/` 資料夾與 `圖片對照表.txt`。
- 匯出 Word 文件：產生自包含圖片的 `.docx`，不需要在貼上後重新從 Plurk 載入圖片。
- 保留常見文字格式，包括粗體、斜體、底線、刪除線、code、上標、下標、超連結與換行。

圖片能否在貼上後顯示，仍取決於目標編輯器；需要穩定保存圖片時，建議使用 ZIP 或 Word 匯出。

## 安裝

1. 開啟 `chrome://extensions/`
2. 開啟右上角「開發人員模式」
3. 點「載入未封裝項目」
4. 選擇本資料夾
5. 打開一則 Plurk 交流頁。
6. 點工具列上的 Extension 圖示開啟側邊欄。
7. 在側邊欄按「擷取目前噗文」。
8. 選擇需要的輸出方式：複製含格式內容、複製純文字、下載圖片與表符，或匯出 Word 文件。
9. 若使用複製功能，在目標應用程式貼上；若使用下載或匯出功能，選擇檔案儲存位置。

側邊欄預設不會隨 Plurk 頁面載入自動開啟。開啟後會維持開啟狀態，直到使用者主動關閉。

## 建議使用方式

- 要貼到 Google Docs：先擷取內容，再使用「複製含格式內容」。
- 要讓圖片維持原本顯示大小：使用「複製含格式內容（維持圖片尺寸）」。
- 要取得較高解析度圖片：使用「複製含格式內容（使用原圖）」。
- 要保存文字與圖片素材：使用「複製純文字」和「下載圖片與表符」，並依 ZIP 內的對照表配對。
- 要製作可直接開啟的文件：使用「匯出 Word 文件」。

## 尚待實機確認

1. 2026 年 Plurk 實際 DOM class 是否完全符合 `content.js` selector。
2. Google Docs 對 `data:` 圖片的實際貼上行為。若 Docs 過濾 data URI，extension 會對無法內嵌的圖片使用原始 Plurk 圖片網址；必要時下一版可改成另一種圖片搬運策略。
3. 自訂表符若不是由 `*.plurk.com` 提供，可能無法被 extension 主動下載，但 HTML 仍會保留原始網址。

## v0.5 擷取核心修正
- Google Docs 富文字＋圖片複製功能完全沿用 v0.4，`popup.js` 未修改。
- 保留純文字輸出、保留發言者、保留圖片 / 表符選項。
- 移除所有「依留言內容 / fingerprint 去重」邏輯。
- 依 Plurk 真實資料識別：
  - `data-pid` = 噗文 ID
  - `data-rid` = 回覆 ID
- 河道模式主噗：用 `#plurk_cnt_<pid>` 擷取。
- 獨立頁主噗：用 `[data-type="plurk"][data-pid="<pid>"]` 擷取。
- 回覆優先從 `.list-container .list` 的 canonical response DOM 擷取。
- 僅在同一個 `data-rid` 出現多份 DOM 時去重；不同 `data-rid` 即使內容完全相同也全部保留。

## DOCX 可靠模式

- 新增「匯出 DOCX（可靠模式）」按鈕，原有複製、純文字及圖片下載功能維持不變。
- 匯出時會先下載圖片與表符，並將檔案內容直接嵌入 DOCX；上傳到 Google Drive 後可用 Google 文件開啟，不依賴貼上後再向 Plurk 載入圖片。
- DOCX 採 Google Docs 友善的 Arial 11 pt、Letter 紙張與 1 吋邊界，並保留發言者、段落、行內格式、連結及圖片位置。
- 無法下載或轉換的個別圖片會改成文字標記，其餘內容仍會正常匯出。
- 支援 Plurk 表符 CDN 將 PNG、JPEG、GIF、WebP 或 SVG 回傳為 `application/octet-stream` 的情況；會先檢查實際檔頭，再供 DOCX 嵌入與圖片下載共用。

- 「複製預覽內容」會複製預覽中的文字與格式；勾選保留圖片與表符時，也會一併帶入。

## v1.0

- 版本號更新為 `1.0.0`；Chrome icon 尺寸可自行準備 16、32、48、128 px PNG，未內建特定 icon。
- 「複製格式化內容」狀態會顯示圖片來源數量，並說明圖片顯示取決於目標編輯器。
